# VCC-001 — Projeto Android inicial

## Estrutura criada
- Gradle Kotlin DSL, Android Gradle Plugin 8.7.3 e Kotlin 2.0.21
- Android SDK 35, minSdk 26, Java 17, Compose e Material 3
- MainActivity inicial e teste unitário de bootstrap
- Gradle Wrapper configurado para Gradle 8.10.2

## Codespaces — primeiro arranque
O JAR binário do Gradle Wrapper não está incluído neste commit. Para o gerar no Codespace, executa:

```bash
sudo bash .devcontainer/install-gradle.sh
./gradlew clean assembleDebug
```

A geração do wrapper deve criar `gradle/wrapper/gradle-wrapper.jar`; faz commit do JAR gerado e do `gradlew` com permissão de execução para que os próximos clones possam compilar diretamente.

## Nota
O build não foi executado neste ambiente; requer SDK/Gradle e ligação a Maven/Google.
