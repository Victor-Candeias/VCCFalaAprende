# VCCFalaAprende
🗣️ **VCC Fala &amp; Aprende** — Aplicação Android de apoio à terapia da fala infantil! 🌈 Inclui jogos educativos, pronúncia, sons, sílabas, vocabulário, leitura, escrita e gravação de voz. Com planos personalizados, acompanhamento da evolução e área para pais e terapeutas. Funciona offline! 🎯
